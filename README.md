# Golfam Production — نسخه اولیه

سامانه PWA فارسی برای ثبت گزارش تولید، مصرف مواد اولیه و توقفات دستگاه‌ها.

## اجرای سریع
این پروژه فایل‌های استاتیک است و با GitHub Pages یا هر هاست استاتیک قابل انتشار است. برای تست محلی، از یک وب‌سرور محلی استفاده کنید؛ بازکردن مستقیم `index.html` ممکن است به‌دلیل ماژول‌های جاوااسکریپت کار نکند.

## نکته مهم درباره این نسخه
- بدون تنظیم Supabase، برنامه در حالت آزمایشی محلی کار می‌کند و اطلاعات فقط در همان مرورگر ذخیره می‌شود.
- حالت آزمایشی برای استفاده چندگوشی یا اطلاعات واقعی کارخانه مناسب نیست.
- برای فعال‌سازی همگام‌سازی واقعی، پروژه Supabase و جداول/سیاست‌های SQL باید راه‌اندازی شوند.
- فایل `app.js` در این نسخه، اسکلت رابط کاربری و فرم‌های اولیه را فراهم می‌کند؛ اتصال کامل CRUD ابری و مدیریت نقش‌ها مرحله بعدی توسعه است.
- هرگز `service_role` key را در فایل‌های فرانت‌اند یا GitHub قرار ندهید.

## راه‌اندازی PWA
1. فایل‌ها را در یک مخزن GitHub قرار دهید.
2. در Settings → Pages، انتشار از شاخه `main` و پوشه `/ (root)` را فعال کنید.
3. لینک HTTPS سایت را در Safari آیفون یا Chrome اندروید باز کنید.
4. در iPhone: Share → Add to Home Screen.
5. در Android: منوی مرورگر → Install app / Add to Home screen.

## راه‌اندازی Supabase
1. در https://supabase.com یک پروژه بسازید.
2. از Project Settings → API، مقدار Project URL و `anon`/publishable key را بردارید.
3. آن‌ها را در `config.js` قرار دهید.
4. اسکریپت `supabase/schema.sql` را در SQL Editor اجرا کنید.
5. برای تعیین اولین مدیر، دستور انتهای فایل SQL را با ایمیل حساب مدیر اجرا کنید.

## ساختار پیشنهادی داده
- profiles: نقش و مشخصات کاربران
- devices: دستگاه‌ها و اپراتورهای اختصاص‌یافته
- products: فهرست محصولات
- materials: فهرست مواد اولیه
- daily_reports: گزارش روزانه که مدیر ایجاد می‌کند
- production_entries: مقدار تولید و شماره بچ
- material_usages: مصرف مواد اولیه
- downtime_entries: توقفات دستگاه‌ها

## قواعد کاری مورد توافق
- مدیر گزارش روزانه را ایجاد می‌کند.
- مدیر دستگاه‌ها را تعریف و اپراتورها را به دستگاه‌ها اختصاص می‌دهد.
- اپراتور فقط اطلاعات دستگاه اختصاصی خود را ثبت می‌کند.
- تولید شامل محصول، مقدار، واحد، وزن هر واحد، وزن کل محاسباتی و شماره بچ است.
- مصرف مواد اولیه چندردیفی است.
- توقفات متعدد مجاز است؛ هم‌پوشانی زمانی برای یک دستگاه و گزارش نباید ثبت شود.
- مدیر گزارش را نهایی می‌کند؛ پس از نهایی‌شدن، اپراتور اجازه تغییر ندارد.
- زمان کارکرد دستگاه = ۲۴ ساعت منهای مجموع توقف‌ها.
